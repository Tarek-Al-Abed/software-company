# SoftTech Website

A simple, responsive website for SoftTech, a fictional software company. The page introduces the company, highlights its services, and provides contact information.

## Features

- Header with SoftTech logo and navigation links
- Hero section with a call-to-action
- Five service cards
- About section
- Responsive footer with services, solutions, company links, and social media links
- Layout adapts to mobile screens

## Built With

- HTML5
- CSS3

## Run the Website

1. Clone or download this repository.
2. Open `index.html` in a web browser.

No additional packages or build steps are required.

## Project Files

- `index.html` — page content and structure
- `style.css` — page styles and responsive layout
